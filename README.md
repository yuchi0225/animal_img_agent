# 單頁教學圖卡生成專案

本專案用於整理素材並分階段產出風格統一的 **A4 直式單頁日系可愛介紹海報**（HTML 完整圖解版 + AI 繪製插畫海報 PNG）。

## 資料夾結構

- `notes/`：第一階段產出的整理筆記（`.md`）
- `html/`：第二階段產出的 A4 直式單頁海報（`.html`）
- `img/`：第三階段產出的日系扁平插畫海報（`.png`）
- `STYLE_GUIDE.md`：視覺風格、配色（A+C）、版面與命名統一規範

## 檔案命名對應

依編號與主題一一對應：

```text
notes/001-主題.md  →  html/001-主題.html  →  img/001-主題.png
```

## 分階段作業流程（每階段確認後才進行下一步）

1. **Stage 1 — 素材整理筆記（`notes/`）**
   - 提供文字、PDF 或圖片素材。
   - 依海報單頁資訊量整理為結構化 `.md` 筆記（含主標、副標、分類標籤、核心重點、小知識/小結）。
   - **確認無誤後**進入 Stage 2。
2. **Stage 2 — HTML 單頁海報（`html/`）**
   - 依 `STYLE_GUIDE.md` 產出 A4 直式單頁 HTML 海報（全直角、左上角標題、彈性模組化內容）。
   - **確認畫面與排版後**進入 Stage 3。
3. **Stage 3 — PNG 插畫海報（`img/`）**
   - 依 `STYLE_GUIDE.md` 透過 AI 生成日系可愛扁平 / Risograph 風格插畫海報 PNG（左上角主標 + 主視覺插畫 + 3～5 個精簡關鍵標籤）。
   - **確認成品後**即完成該張圖卡！
